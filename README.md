# Soft Chaos · Maria Eduarda

Landing page de nail art autoral para Maria Eduarda, inspirada na identidade visual Soft Chaos.

## Desenvolvimento

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm build
pnpm preview
```

O GitHub Actions gera o site em cada atualização de `homolog` e `deploy`. A publicação no GitHub Pages acontece após a integração de `homolog` em `deploy`.
